Privacy Policy

ARBsistant WHOOP Integration
Last updated: February 9, 2026

Overview

This is a personal integration that connects WHOOP data to ARBsistant, a private AI assistant. This application is not intended for public use.

Data Collection

This integration accesses WHOOP data including recovery scores, sleep data, strain, workouts, and body measurements solely for the account owner's personal use.

Data Usage

All data retrieved from WHOOP is used exclusively to provide personalized health and fitness insights to the account owner. Data is stored locally and is not shared with any third parties.

Data Storage

Data is stored locally on a private server controlled by the account owner. No data is transmitted to external services beyond what is necessary for the WHOOP API connection.

Data Deletion

Users can revoke access at any time through their WHOOP account settings. Upon revocation, all locally stored WHOOP data will be deleted.
